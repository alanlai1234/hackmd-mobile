# Hackmd Mobile App
Utilizes [hackmdio/api-client](https://github.com/hackmdio/api-client/tree/develop), implemented in React Native with performance and app size in mind.
* Custom nitro module which shares webview for markdown displaying
* Optimized state management
* As much native libraries as possible

Current features:
* Folders support(in development)
* Light/Dark theme support
* Note streaming
* Note editing(with basic syntax highlight)
* Tags
* Search Notes
* Workspaces
* Add/Rename/Delete Note

Ongoing:
* Language support
* Note editing auto complete list notation
* Note editing updating
* Rich text editing
* Download current markdown
* linking url(open hackmd link into the app)
* markdown rendering CSS(need official help)
